Performance

Degraded, because it is a web browser build.

Frame rate, view distance, and crowded fights are lower than the Windows and Mac versions. The browser build gives up that headroom so the fight can run inside a browser tab.

The desktop download is the full-performance way to play. No gameplay is locked behind either version. Same factions, same front, less room to spare in the browser.
